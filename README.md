A tiny chess engine in 4 KB of Python: a 0x88 board, negamax alpha-beta with iterative deepening, quiescence search, a transposition table, killer moves and null-move pruning, evaluated by material plus piece-square tables and the bishop pair. The search runs to a fixed node count, never to a clock. Built by an AI agent for make.fun's tiny-chess-01 bounty.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
